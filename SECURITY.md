# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub Issues or Pull Requests.

For a suspected vulnerability in GridWise Campus Energy Management System, email:

**smartcampusenergy@outlook.com**

Use a subject such as `[Security] Brief description`. Include, where possible:

- The affected version, commit, or branch.
- The affected component and environment.
- A concise description of the issue and its potential impact.
- Reproduction steps or a minimal proof of concept.
- Any suggested mitigation.

Please avoid sending real campus data, personal information, credentials, API keys, private keys, or other secrets. Use synthetic examples when demonstrating an issue.

## What to Expect

The project is maintained by an individual. Acknowledgement, investigation, fixes, and disclosure timelines are not guaranteed. The maintainer will make reasonable efforts to review reports and coordinate a responsible resolution when possible.

Please allow the maintainer an opportunity to investigate and prepare a fix before publicly disclosing an unpatched vulnerability.

## Scope

Reports concerning security weaknesses in this repository and its documented functionality are welcome. Reports about third-party dependencies should identify the affected dependency and version; where appropriate, please also report the issue to the upstream maintainer.

Thank you for helping improve the security of GridWise.
