## 1. 阶段目标与完成情况 / Goals and completion

本阶段完成了桌面端电网与单电池参数配置。默认值仍来自 `examples/synthetic-day.json`；用户可配置购电上限、容量、充放电功率、初末 SOC 能量和两种效率。经公共校验器生成的冻结参数对象真正写入求解场景，并经过原有 CLI、Pyomo + HiGHS、独立审计、运行目录发布和安全读取链。/ The desktop now exposes validated grid and single-battery parameters. Values are written into the actual scenario and flow through the unchanged solver, independent auditor and verified-run reader.

参数变化会清除旧指标、图表和当前历史选择，但保留已通过的 CSV 质量结果。读取历史运行时，界面从安全读取后的 `scenario.json` 恢复该次实际设备参数。不同设备参数会改变完整场景 SHA-256，因此不能成为彼此的“同场景纯电费参考”。/ Parameter edits invalidate stale results while preserving CSV quality. Historical values are restored from verified scenario bytes; full-scenario hashing prevents mismatched cost references.

## 4. 关键实现与设计决策 / Key implementation decisions

### 公共设备结构 / Public equipment structure

`DeviceParameters` 使用与当前 JSON 契约相同的八项值：`grid_max_kw`、`capacity_kwh`、`initial_kwh`、`terminal_kwh`、`max_charge_kw`、`max_discharge_kw`、`charge_efficiency`、`discharge_efficiency`。初末 SOC 的实际单位为 kWh，不是百分比。校验规则与模型契约一致：有限、非负、≤10¹²；容量及效率为正；效率≤1；初末能量≤容量。/ The frozen structure mirrors the existing JSON contract. Initial and terminal SOC are kWh energy, not percentages.

没有增加主观的“小设备/大设备”额定范围。合法的零购电或零功率配置仍可能不可行；该情况交给现有求解状态检查并失败关闭，而不是静默修正。/ No arbitrary engineering rating range was added. Valid-but-infeasible values remain a solver failure.

### 运行可追溯性 / Run traceability

实际设备参数已经包含在 `scenario.json`，并被 `manifest.json` 的大小和 SHA-256、`summary.run.scenario_sha256`、独立审计器和安全读取共同覆盖。因此没有增加清单格式 3 或重复元数据。哈希可检测内容变化，不证明参数真实或获授权。/ The existing verified scenario already provides a single source of truth, so no artifact schema migration or duplicate metadata was added.

### GUI 状态 / GUI state

设备控件只在 Tk 主线程读写，求解仍在原后台流程。运行时控件禁用。参数改变只使计算结果失效，不要求重复解析未变化的 CSV。历史选择是显式操作；加载后恢复该运行实际设备值，而不是把它误标为当前输入参数产生的结果。/ Tk ownership and worker boundaries are unchanged. Loading a history item explicitly restores its verified equipment values.

## 5. 核心数学模型边界 / Mathematical model boundary

变量保持不变：购电 `G[t]`、充电 `C[t]`、放电 `D[t]`、光伏利用 `P[t]`、步末能量 `E[t]` 和互斥二元变量 `z[t]`。/ Variables are unchanged.

目标保持不变：

`min Σ G[t] × price[t] × step_hours`

约束保持不变：功率平衡、带效率的 SOC 递推、`0≤E≤Emax`、电网/充放电功率上界、充放电互斥和终端 SOC；可选峰值模式仅增加 `G[t]≤K`。自定义值只替换这些约束的参数，不增加目标项。/ Custom values parameterize the existing balance, SOC, bound, exclusivity and terminal constraints; they do not add an objective term.

独立校验仍由 `core.validate_result` 与标准库 `audit_exports.py` 分别重算输入回显、功率平衡、SOC、功率/容量、互斥、终端值、电费、购电量和峰值。本阶段没有放宽 `0.00001` 绝对容差。/ Existing in-process and independent arithmetic checks remain unchanged.

## 11. 未解决问题与风险 / Open issues and risks
