## 4. 修改文件及设计 / Changes and design

- 新增 `src/gridwise/run_storage.py`、`tests/test_run_storage.py`、`docs/run-history-storage.md`：有界、严格的本地目录偏好；仅用户点击“保存目录”才写设置。Windows 默认设置路径 `%LOCALAPPDATA%\GridWiseCampus\desktop.json`，只保存格式版本与目录路径。保存采用本次私有暂存文件和单文件替换；失效设置保留原件、界面显示原因并退回临时目录。所选目录须已存在且不能是链接或 junction。/ Explicit, bounded local preference; no automatic migration or deletion.
- 修改 `src/gridwise/desktop.py`、`tools/smoke_desktop_verified.py`、`tests/test_desktop_ui.py`：显示当前根目录及临时/已保存状态；恢复后异步刷新；烟测使用独立新 Python 进程验证历史重读。/ The desktop shows root state and restores history on restart.
- 修改 `src/gridwise/run_artifacts.py`、`tests/test_run_artifacts.py`：验证末尾复核目录身份、修改时间及精确条目集合。修复前，审计期间注入 `unexpected.txt` 后仍可返回 `VerifiedRun`；修复后抛 `RunArtifactError`。文件修改、替换、删除，重复 JSON 键、非有限值、junction 模拟及并发读取继续回归。/ A deterministic injection reproduced and then closed a visible directory-mutation gap.
- 修改 `tools/diagnose_tk_runtime.py`、`tests/test_tk_runtime_diagnostics.py`：Tcl 初始化失败时仍形成结构化结果和堆栈；限制 `count=1..100`、`repeat=1..20`、每子进程 45 秒、stdout 64 KiB、stderr 8 KiB、总证据 JSON 2 MiB。超限仅终止本诊断创建的子进程。/ The probe preserves startup/focus failure evidence with bounded time and captured output.
- 更新双语 `README.md`、`docs/architecture.md`、`docs/interface-spec.md`、`docs/test-plan.md`、`docs/run-artifact-contract.md`；新增本报告。/ Bilingual user and contract documentation updated.

## 5. 缺陷复现与修复证据 / Reproductions and repairs

1. **运行目录并发变动 / Concurrent directory mutation:** 在 `summary.json` 读取后注入额外文件，修复前 `test_reader_detects_new_directory_entry_during_verification` 未抛异常（定向测试 1 failed、3 passed，退出 1）；末尾复核后该组 5 passed、退出 0。此修复只覆盖可观察变动，不保证抵御能伪造清单或恢复目录元数据的恶意本机写入者。/ Visible mutation is detected; adversarial provenance is not established.
2. **诊断初始化缺口 / Tcl startup gap:** 注入 `tk.Tcl()` 失败，修复前异常直接逃出、没有 JSON（退出 1）；修复后 `test_tcl_initialization_failure_produces_diagnostic_json` 通过。注入焦点命令失败后，诊断 JSON 包含完整的注入异常堆栈。/ Injected failures are now captured; this does not explain the intermittent real failure.
3. **真实 Tk 失败 / Observed Tk failures:** `python -m pytest -q tests/test_run_storage.py tests/test_desktop_ui.py` 曾为 1 failed、37 passed，报 `invalid command name "tk_focusNext"`。其后一次完整 pytest 为 1 failed、315 passed、1 skipped，注入焦点故障的测试却在真实 Tcl 初始化处报 `invalid command name "tcl_findLibrary"`。该单元测试本应只检验异常序列化；将其改用确定性假 Tk 夹具后，真实 Tk 探针测试仍保留。初次失败 pytest 输出在会话工具记录中；临时证据目录 `%TEMP%\[LOCAL_TEMP_ENTRY]` 保存后续原始探针 JSON、重复测试日志及一份**从失败输出转录的摘要 JSON**。摘要 JSON 不是原始完整堆栈，第二次真实失败亦没有同步生成诊断 JSON，均属证据缺口。独立探针与重复测试未再次复现，根因 `UNKNOWN`。/ The injected serialization test is now deterministic while real Tk probes remain. Both observed runtime failures are retained as evidence; neither has a complete simultaneous diagnostic snapshot.

## 8. 证据边界、NOT_RUN 与后续 / Evidence limits and next steps

- **动态验证 / Dynamic:** Windows 合成数据、临时设置与运行目录、独立审计、文件故障注入、8 线程 20 次并发安全读取、实际 Tk 窗口及新进程恢复。/ These exact paths were run.
- **静态审查 / Static:** 模型、数据质量、审计器及旧 CLI 均未改动；无远程和正式许可证。/ Protected contracts were unchanged.
- **NOT_RUN:** Linux/macOS、真实持久用户目录长期运行、真实 junction 创建、物理键盘/屏幕阅读器、恶意本机写入者、断电恢复、跨文件原子提交及长时间耐久性。/ No claim is made for these conditions.
- **遗留风险 / Residual:** Tk/Tcl 间歇故障根因 `UNKNOWN`；新目录末尾复核缩小可观察竞态，但不能消除所有 TOCTOU。设置文件单文件替换不提供断电持久性。默认系统临时目录仍可能由系统清理。/ The intermittent Tk cause and stronger filesystem guarantees remain open.
- **建议 / Next:** 在可复现 Tk 错误的环境中同时保存原始完整异常堆栈、`info commands tk_focusNext`、`auto_path` 和库文件状态；确认需要长期保留时，由用户选定受控目录并建立外部备份。/ Capture live failing interpreter state next time, and use an explicit backup policy for long-term archives.
