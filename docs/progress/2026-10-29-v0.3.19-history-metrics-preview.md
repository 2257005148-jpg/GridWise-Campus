# GridWise Campus v0.3.19 Phase 3 — 历史运行指标预览 / Historical run metrics preview

日期 / Date: 2026-10-29

## 1. 阶段目标与完成情况 / Objective and completion

本阶段在既有历史运行 Treeview 上增加用户主动触发的指标预览。只有当前 CSV 已通过质量检查、且所选历史记录为 `VALID` 时，预览按钮才可用。预览重新安全读取所选运行，并复用现有图表准备链路完成逐行对齐和指标重算。

Displayed values:

- 电费 / Cost (`CNY`)
- 购电量 / Grid energy (`kWh`)
- 峰值购电功率 / Peak grid power (`kW`)
- 优化模式 / Optimization mode
- 峰值上限 / Peak cap (`kW`; `—` when not applicable)

未实现批量预览、运行时间排序、PDF 导出或任何新的优化功能。

## 3. 关键实现与设计决策 / Key implementation and design decisions

1. `preview_verified_run()` 首先调用 `read_verified_run()`，随后将安全读取的 `summary.json` 与当前已校验 CSV 交给既有 `prepare_visualization_data()` 路径；未在预览模块或 Tk 层重写指标公式。
2. 预览返回不可变的 `RunHistoryPreview`，统一携带运行标识、模式、峰值上限、三项重算指标、单位和完整性状态。
3. 仅用户点击“预览指标 / Preview Metrics”才读取所选运行；表格刷新、搜索、筛选和排序不会预览，也不会触发新的磁盘扫描。
4. `INCOMPLETE`、`DAMAGED`、当前 CSV 未就绪、清单损坏或输入错配均失败关闭，不显示部分指标。
5. 更换选择、CSV、步长、设备参数、策略、峰值上限或运行根目录，以及开始新任务、取消、失败和 generation 变化时，旧预览立即失效。
6. 后台结果除既有 generation 检查外，还核对返回的运行标识与当前选中有效记录；迟到结果不能覆盖新选择。
7. 预览不运行求解器、不执行独立审计、不发布或修改运行产物；它只复核已发布运行的完整性和当前输入对齐。

### 实际动态验证 / Dynamically verified

- `VALID` 的纯电费和峰值上限运行显示正确模式、上限、指标及单位；
- 预览使用安全读取与现有指标准备函数；
- 当前 CSV 行数/内容错配、产物损坏和预先取消均失败关闭；
- `INCOMPLETE` / `DAMAGED` 不能触发预览，原状态与错误详情仍保留；
- 更换选中运行或输入 generation 后，迟到结果被丢弃；
- 预览失败与取消均清空旧指标，取消不显示为成功；
- 搜索、筛选、排序不触发预览或额外磁盘扫描；
- 新增预览控件未破坏既有键盘焦点遍历测试。

### 静态审查 / Static review

- 预览调用链未引用求解器、独立审计器或发布函数；
- Tk 层只格式化控制层返回的值和单位，不读取 JSON/清单，不计算业务指标；
- `core.py`、`data.py`、`cli.py`、`run_artifacts.py`、`reports.py` 和两个审计器均未修改。

### 未执行 / NOT_RUN

- 完整 pytest：按本阶段要求 `NOT_RUN`。
- Phase 1 / Phase 2 整组回归：未重复执行，仅运行直接受影响的排序无预览和焦点用例。
- 人工可见 GUI 烟测及截图：`NOT_RUN`。
- Linux、macOS、托管 CI：`NOT_RUN`。
- 真实校园数据、设备或网络服务：`NOT_RUN`。

## 5. 性能、安全与数据边界 / Performance, safety, and data boundaries

- 每次点击只读取一个所选运行；没有批量读取、缓存文件或后台预加载。
- 原 `MAX_HISTORY_ENTRIES=50` 与 `MAX_HISTORY_SCAN=1000` 未改变。
- 预览依赖当前 CSV 通过质量检查，并复用现有时间戳、输入回显和指标对齐验证。
- 完整性验证和输入对齐不证明数据来源真实性，也不重新证明求解最优性。
- 原始 CSV、历史运行目录及产物均只读；本阶段没有生成新的运行结果。
