## 6. 关键数值和计算依据 / Numerical results and basis

两方案使用同一 `examples/synthetic-day.json`、1 小时时步、逐时电价和峰值定义 `max(grid_kw)`。优化购电费 `Σ(grid_kw × price_cny_per_kwh × step_hours)` 为 **131.01108033240996 元**（显示 131.01），无储能基线为 **162.50 元**；差额约 **31.49 元**。购电量分别为 **247.02216066481995** 与 **240.0 kWh**，峰值分别为 **90** 与 **60 kW**，弃光均为 0 kWh。降低电费没有降低峰值或购电量。 / Both use the same source and peak definition. Cost fell, while grid energy and peak rose.

独立审计以 CSV 与原始场景重新计算每行功率平衡、SOC、光伏拆分、成本、购电量与峰值，并与汇总逐项比较；绝对容差为每项单位的 `0.00001`，校验前不舍入。 / The standard-library auditor recalculated physical and aggregate quantities with absolute tolerance 0.00001 and no pre-check rounding.

## 7. 数学模型与独立校验 / Model and independent checks

**静态审查，模型未改 / Static review, model unchanged:** 变量为逐时 `grid`, `charge`, `discharge`, `pv_used`, `soc` 和二元 `mode`；目标为最小化 `Σ grid[t] × price[t] × step_hours`。约束含 `grid + discharge + pv_used = load + charge`、`soc[t] = prior + step_hours × (ηc × charge − discharge / ηd)`、初始/终端 SOC、容量与功率上限、光伏使用上限及充放电互斥。无储能基线将充放电上限设为 0；求解器必须返回 `ok` 和 `optimal`。 / Variables, objective and constraints remain the existing cost MIP; baseline disables the battery.

**动态验证 / Dynamic validation:** 上述合成结果通过独立 CSV 算术审计；这证明所给文件之间的一致性与所检查物理约束，不能证明输入真实性或求解器执行可信。 / Passing arithmetic checks does not establish authentic input or trusted solver execution.
