# GridWise Campus v0.3.18 阶段报告 / Stage Report

日期 / Date: 2026-10-28

## 1. 阶段目标与完成情况 / Goals and completion

本阶段把 v0.3.17 已有的冻结 `RunDiagnostic` 接入 Tk 桌面界面。新增紧凑双语摘要、可展开只读详情和复制入口；没有重写分类规则，也没有修改模型、数据、CLI、运行产物或审计器。/ This stage presents the existing immutable diagnosis in the Tk desktop through a compact summary, expandable read-only details and clipboard copy. Classification, model, artifact and audit contracts remain unchanged.

已完成 / Completed:

- 九种既有类别的双语可见映射；
- 类别、阶段、摘要、可用 solver status/termination、证据和人工建议的紧凑展示；
- 可聚焦、可选择、可滚动的详细文本，包含原异常与有限异常链；
- 复制完整详情；剪贴板失败时保留诊断并写入既有日志；
- `UNKNOWN` 明确显示“证据不足，无法确定根因”；
- CSV、步长、设备、策略、峰值上限、运行根目录、新任务和成功结果清除旧诊断；
- 用户取消及旧 generation 结果不创建或恢复虚假失败；
- 失败后的图表、指标和报告资格继续按原逻辑失效。

## 3. 关键实现与设计决策 / Decisions

1. 面板只格式化 `RunDiagnostic`，不从异常文本重新分类；`diagnostics.py` 未修改。
2. `INFEASIBLE` 的 solver status/termination 由已有严格分类结果进入摘要和详情，未放宽证据要求。
3. 诊断状态属于当前 UI generation；既有 generation 检查仍是拒绝迟到结果的权威边界。
4. 详情默认折叠，避免挤占指标和图表；展开后使用只读 `Text` 和滚动条。
5. 复制异常只改变状态提示并追加日志，不清除诊断、不修改任何参数。
6. 普通取消走原取消分支，不调用失败诊断展示。
