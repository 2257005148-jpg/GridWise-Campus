# GridWise Campus v0.3.4 阶段报告 / Desktop quality and release-readiness review

## 1. 阶段目标与结论 / Goal and conclusion

**动态验证 / Dynamic verification:** 本机 Windows 11 上复核了 Tk 键盘流程、取消、关闭清理、合成比较及独立审计。最终定向测试 **73 passed**，完整 pytest **230 passed**；可见 Tk 窗口完成 **20 次连续 + 1 次恢复后的真实合成比较**，另有一次正在运行的子进程被取消，错误 CSV 被拦截。 / Keyboard cancellation, cleanup, real synthetic comparisons and the export audit were exercised.

**发布结论 / Release decision:** 当前仍不具备对外发布依据。正式项目许可证未确定；真实跨显示器 DPI、人工物理键盘焦点观察及屏幕阅读器验收未执行。 / A public release is not cleared.

## 3. 真实问题与修复 / Reproduced defects and fixes

1. **无显式键盘取消 / No explicit keyboard cancellation:** v0.3.3 运行界面没有 Cancel 控件；新增 Esc/取消回归先以 `AttributeError: cancel_button` 失败。现可通过 Tab 聚焦取消按钮或 Esc 发出取消事件；等待后台操作退出后才恢复按钮，取消不显示审计成功。质量检查取消后也拒收迟到结果，取消后可再次运行。 / Cancellation is now keyboard reachable and fail-closed.
2. **窗口过早退出 / Window closed before cleanup:** 延迟释放临时目录的合成回归先证明 `root.winfo_exists()==0`，而后台清理尚未完成。现跟踪已启动工作任务；关闭窗口先请求取消，等待当前和输入切换后仍在清理的旧任务送回完成事件，再销毁 Tk。关闭期间忽略新操作和结果。 / Closing now waits for background cleanup.

**动态清理证据 / Cleanup evidence:** 一次可见窗口烟测完成 21 次真实比较（前 20 次连续，取消后再成功 1 次）、1 次被取消的运行和 1 次无效 CSV 拦截。脚本记录的 **43 个**已启动子进程全部结束；本阶段 `gridwise-` 工作线程与 `gridwise-ui-*` 临时目录均无新增残留；合成原始 CSV 与无效 CSV 的 SHA-256 在操作前后不变。另一个定向测试让 10 秒睡眠子进程在取消后被回收。 / These are short synthetic checks, not a long-duration guarantee.

## 4. 键盘、DPI 与辅助技术证据 / Keyboard, DPI and accessibility

- **动态验证 / PASS:** Tk 事件与焦点断言覆盖空格选择文件、检查、运行，方向键切换图表页签，Tab/Shift+Tab 顺序、只读日志聚焦、Page Up/Down 滚动、取消按钮/Esc、运行时禁用状态、结束后恢复。四档程序化 Tk scaling（1.0、1.25、1.5、2.0）下，900×650 最小窗口的取消按钮未越过视口；既有卡片/图表断言复跑。 / Automated Tk focus and layout checks passed.
- **静态审查 / Static:** `clam` 的按钮和页签布局包含 focus 元素，Entry 在 focus 状态有边框色；这只能说明主题提供焦点绘制机制。 / Theme inspection does not prove every focus indicator is visually clear.
- **实际窗口观察 / Observed GUI:** Windows Computer Use 成功读取窗口和截图，当前尺寸可见中英双语标题、输入区、三类指标卡与五个页签；常驻悬浮窗遮挡上部，无法据此宣称无遮挡的焦点视觉验收。UI Automation 控件树将多处 Tk 控件暴露为匿名 `Pane`，控件名/角色证据不足。 / The screenshot and UIA tree reveal a semantic accessibility gap.
- **NOT_RUN:** 物理键盘人工盲操作、屏幕阅读器、真实原生 125%–200% 缩放、不同 DPI 显示器间移动及 `WM_DPICHANGED`。本阶段 `GetSystemMetrics(SM_CMONITORS)=1`；未修改系统缩放或注册表。 / Native multi-monitor and assistive-technology acceptance require another environment.

## 5. 发布前静态审查 / Static release review

`pyproject.toml` 直接运行依赖声明为 `pyomo==6.9.5`、`highspy==1.15.1`，测试附加依赖为 `pytest==8.4.2`；本机安装版本与之相符。Windows 约束文件还记录 NumPy 2.5.4、PLY 3.11、Colorama 0.4.6、Iniconfig 2.3.1、Packaging 26.3、Pluggy 1.7.0、Pygments 2.21.0。`setuptools>=75` 仅在构建系统声明，本机运行环境查询不到其已安装元数据，不能声称本机已验证构建隔离安装。未发现桌面或控制层的调试 `print`/断点；HiGHS 由 Pyomo 后端使用，未发现明确多余的直接运行依赖，但这是静态判断。 / Declared runtime versions match the local interpreter; build-tool verification is incomplete.

项目无正式 `LICENSE`；本机包元数据仅显示 Pyomo BSD-3-Clause、highspy MIT 等声明，不能推定本项目获得发布授权或第三方许可义务已完成核查。`pyproject.toml` 的包版本仍为 `0.1.0`；文档已说明 v0.3.x 是内部阶段编号，不是已发布版本。 / Project licensing remains undecided.

桌面交互在唯一临时目录内写合成场景和导出，不写原 CSV；上下文退出负责清理。命令行 `gridwise.cli` 会覆盖用户指定输出目录中的同名导出文件，这是发布前应明确提示或另设安全策略的静态风险，本阶段未改变既有 CLI 契约。异常日志仍保留异常类型和具体文本；质量报告在主视图只列前 8 条并显示剩余数量，完整辅助技术可读性仍需设计。 / Output overwrite and accessibility semantics remain review items.
