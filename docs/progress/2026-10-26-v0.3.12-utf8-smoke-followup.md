日期 / Date: 2026-10-26

## 1. 目标与结论 / Objective and conclusion

本轮只调整验收进程的标准输出编码，不修改产品代码、测试代码或既有文档。设置 `PYTHONIOENCODING=utf-8` 后，原桌面烟测命令完整退出 0，先前的 cp950 `UnicodeEncodeError` 未再出现。

The original desktop smoke command completed successfully after setting UTF-8 process output. No product behavior was changed.

但是，烟测脚本使用 `TemporaryDirectory(prefix="[LOCAL_TEMP_ENTRY]")`，正常结束时会删除该次运行根目录。脚本只输出运行名，不输出临时根路径。因此无法对烟测本身生成并已删除的目录继续执行单独的外部审计与安全读取。为遵守“必须使用本次烟测实际路径、不得猜测或复用旧路径”，验收在路径核对后停止。

## 2. 实际命令与退出码 / Executed command

```powershell
$env:PYTHONIOENCODING = "utf-8"
& "[LOCAL_TEMP_ROOT]\[LOCAL_TEMP_ENTRY]\Scripts\python.exe" tools\smoke_desktop_verified.py
$SmokeExit = $LASTEXITCODE
Remove-Item Env:PYTHONIOENCODING -ErrorAction SilentlyContinue
if ($SmokeExit -ne 0) {
    throw "桌面烟测失败，停止后续验收。退出码：$SmokeExit"
}
```

实际退出码 / Actual exit code: `0`
