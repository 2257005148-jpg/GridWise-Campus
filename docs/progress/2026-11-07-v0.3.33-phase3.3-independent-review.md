### 6.2 阻断问题：安装路径占位符会被当作字面目录

README 当前示例包括：

```powershell
py -3.12 -m venv [LOCAL_ENV_ROOT]\gridwise-campus-py312
& [LOCAL_ENV_ROOT]\gridwise-campus-py312\Scripts\python.exe -m pip install -e .
```

PowerShell AST 解析确认 `[LOCAL_ENV_ROOT]\...` 在这些位置是普通字符串/命令路径，不是变量。README 没有说明读者必须替换该占位符：

- 第一条命令会把 `[LOCAL_ENV_ROOT]` 当作相对目录名；
- 后续命令继续调用该字面目录；
- 若读者自行替换为包含空格的路径，未引用形式可能失败；
- 这可能在仓库内产生不期望的环境目录，且不符合“命令可直接理解、可安全复现”的开源 README 要求。

最小修复建议（本轮未实施）：使用已被 `.gitignore` 忽略的仓库本地 `.venv`：

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -e .
& .\.venv\Scripts\python.exe -m pip install -e '.[test]'
```

或者先以 PowerShell 变量定义一个明确、已引用的绝对路径，并在正文解释替换方法。修复后应再次静态核对 README 中的全部命令；本轮没有执行安装命令。
