### 8.1 许可证元数据兼容折中

现代 PEP 639 推荐 `license = "Apache-2.0"` 与 `license-files = ["LICENSE"]`，但 setuptools 官方文档说明该格式从 77.0.0 起支持；本阶段明确禁止修改当前 `setuptools>=75`。因此候选采用仍兼容 setuptools 75 的 PEP 621 旧式 `license = { file = "LICENSE" }`。

该格式已经弃用。使用已审计 setuptools 84.2.1 生成元数据时成功，但给出 2027-02-18 前迁移的弃用警告。未来经维护者授权把构建下限提高到 77+ 后，应迁移到 SPDX `Apache-2.0` 和 `project.license-files`；本阶段不擅自改变构建依赖。
