## 3. 真实问题、复现与修复 / Reproduced issues and fixes

1. **图表受挤压 / Chart collapse:** 修复前在 900×650 窗口、Tk 缩放约 1.333/1.667/2.0/2.667 下，图表区域高度分别约为 160/108/38/1 px；长页签的请求宽度在后三档超过窗口。四个布局测试先以 `4 failed` 复现。修复后可滚动视口保留至少 200 px 图表高度，页签宽度不足时采用短标题，完整双语标题仍绘在图内。 / A scrollable page and compact tabs keep all five charts reachable at the tested factors.
2. **指标卡截断 / Metric clipping:** 双倍 Tk 缩放时每卡请求宽度约 361 px，而原三列实际仅约 278 px。卡片现在按可用宽度重排，优化与基线各占独立行；测试断言实际宽度达到请求宽度。 / Cards reflow and preserve separate units and plan labels.
3. **时间轴重叠 / Time-axis overlap:** 双倍缩放的三处原始长时间标签有重叠，回归先以 `1 failed` 复现。现按日期/时刻与各自 UTC 偏移分两行显示，布局测试确认三个标签边界不重叠。 / Timestamps retain offset information without overlapping in the tested viewport.
4. **运行反馈 / Busy feedback:** 后台任务仅有文字提示。新增不确定进度条，在检查/运行期间显示，取消、完成、失败和关闭时停止；断言先以 `1 failed` 复现缺失，修复后通过。该条不表示求解百分比。 / The activity bar is not a solver progress percentage.

`src/gridwise/core.py`、`src/gridwise/data.py`、`src/gridwise/dashboard.py`、`tools/audit_exports.py`、`tools/audit_history.py` 均未修改。纯电费目标仍为 `min Σ grid_kw × price_cny_per_kwh × step_hours`；UI 仍仅消费 `prepare_visualization_data` 的指标和序列，不计算电费、购电量或峰值。 / Model, data and audit contracts remain unchanged.

## 5. DPI、缩放与异常验证范围 / DPI, resizing and failure scope

- **动态通过 / PASS:** Tk `scaling` 在基准约 1.333 的 1.0、1.25、1.5、2.0 倍下，900×650 窗口保持图表高度、页签宽度、卡片宽度和按钮边界，滚动可到达图表；双倍缩放三处时间标签不重叠。 / Four programmatic Tk scaling factors passed layout assertions.
- **动态通过 / PASS:** 长达 270 字符的无效文件名得到可见质量错误而不崩溃；原有重复运行、场景切换、窗口关闭、求解/审计失败和临时目录测试在定向与完整套件中复跑通过。 / Long-path and existing async/fail-closed regressions passed.
- **未执行 / NOT_RUN:** 真实 Windows 显示设置逐档切换、不同物理高 DPI 显示器、Linux/macOS GUI、托管 CI、真实校园数据和设备。 / Native display scaling, other platforms, hosted CI and live integrations were not tested.

程序化 `tk scaling` 测试**不能证明** Windows 每显示器 DPI 行为正确；界面截图也不是数据真实性或最优性证明。 / Simulated scaling and screenshots have limited evidentiary scope.

## 7. 风险与下一阶段 / Risks and next step
