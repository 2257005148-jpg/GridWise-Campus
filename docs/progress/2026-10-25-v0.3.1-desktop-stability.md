## 3. 关键决策、模型和 Bug / Decisions, model and bugs

- **复现 / Reproduction:** 修复前的 `_run` 在 Tk 回调内同步调用 `run_comparison`；注入 0.3 秒模拟求解后，定时回调在返回前未触发（`timer_fired_before_return=False`）。重复点击的测试在修复前产生 2 次运行。 / The main event loop was blocked and duplicate invocation was reproduced.
- **修复 / Fix:** 工作者只把值或异常写入队列；Tk 控件只在主线程更新。输入改变增加代次、设置取消事件并清空旧结果；重复运行被拦截。CLI 求解与独立审计各默认最多 120 秒，取消或超时杀掉在途子进程。 / Workers never update Tk; cancellation, bounded child processes and generation checks contain stale work.
- **回归 / Regression:** 定向测试覆盖响应、重复点击、旧结果丢弃、关闭取消、残缺图表、错误 CSV、求解超时/失败、审计失败和临时文件清理。 / Targeted tests cover responsiveness, state isolation and fail-closed behavior.
- **模型 / Model:** `src/gridwise/core.py` 未修改；变量、纯电费目标、功率平衡、SOC 和求解契约均沿用原有版本。`tools/audit_exports.py` 与 `tools/audit_history.py` 未修改。UI 从 `data.prepare_visualization_data` 读取成本 CNY、购电量 kWh、购电峰值 kW，无新公式。 / The mathematical model and auditor contracts are unchanged; the UI consumes prepared metrics.
- **数值 / Numeric result:** 合成样例优化电费 131.01 CNY、购电量 247.02 kWh、峰值 90.00 kW；无储能基线分别为 162.50 CNY、240.00 kWh、60.00 kW。两方案由同一场景 JSON 和时间步生成；独立审计复核原件、两 CSV 与汇总 JSON。电费降低不代表购电量或峰值降低。 / Both plans use the same scenario; lower cost does not imply lower energy or peak.

## 6. 风险与证据缺口 / Risks and evidence gaps

- Tk 8.6 测试进程内反复创建独立根解释器偶发 `tk.tcl` 读取失败；测试改为共用一个解释器、每例独立顶层窗口。未证明该环境问题在其他 Python/Tk 安装上存在。 / Repeated root creation was unstable on this host; the test fixture shares one interpreter.
- 900×650 和默认尺寸已通过程序化窗口刷新；人工视觉和高 DPI 检查仍 `NOT_RUN`。 / Window refresh was exercised programmatically; manual visual inspection remains open.
- 本机时间与合成数据不证明真实输入、物理设备或求解性能上限。120 秒仅是交互保护值。 / Synthetic evidence does not establish live-data trust or a performance guarantee.
- 项目正式许可证仍待授权决定，不得据此发布。 / Release licensing remains unresolved.
