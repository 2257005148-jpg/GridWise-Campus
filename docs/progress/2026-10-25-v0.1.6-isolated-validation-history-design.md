## 6. 关键数值与依据 / Numeric results and basis

## 7. 数学模型与独立校验 / Mathematical model and independent check

**静态审查，未修改 / Static review, unchanged:** 变量 `grid[t]`, `charge[t]`, `discharge[t]`, `pv_used[t]`, `soc[t]` 和二元 `mode[t]`；目标最小化 `Σ grid[t] × price[t] × step_hours`。功率平衡为 `grid + discharge + pv_used = load + charge`；SOC 递推为 `soc[t] = prior + step_hours × (ηc × charge − discharge/ηd)`，另含初始/终端 SOC、容量、功率、光伏和充放电互斥约束。求解器需返回 `ok` 与 `optimal`。无储能基线充放电上限为零。 / Cost-only MIP and baseline policy were preserved.

**动态验证 / Dynamic validation:** 本机新环境重新求解合成案例，独立审计通过；没有执行历史模型或真实设备。 / The new Windows environment exercised only the synthetic current model.
