## 3. 关键实现与设计决策 / Design decisions

1. 每一侧先调用现有 `read_verified_run()`，再将其已校验汇总字节交给 `prepare_visualization_data()` 对齐当前 CSV 并重算指标；Tk 不计算业务指标。/ Each side is safely reread and recalculated by the existing data layer; Tk contains no metric formula.
2. 结果采用不可变结构 `HistoricalRunComparison → ComparedRun + ComparisonMetrics`。任一检查失败抛 `DashboardError`，不返回部分结果。/ One immutable result is returned only after every gate passes.
3. 模型版本允许 `cost-mip-v1` 与 `peak-cap-mip-v1` 前缀不同，但要求其 `+sha256.` 后的模型源码摘要一致。/ Policy-specific version prefixes may differ, while model-source digests must match.
4. 无储能基线的电费、购电量和峰值按绝对容差 `1e-5` 再比较，防止不同输入口径被包装为公平实验。/ Baseline metrics are an additional fair-context guard.
5. 输入、时间步、设备参数、策略或运行根目录变化清空旧比较；后台结果通过既有 generation 机制拒收。/ Context changes invalidate comparison state; stale workers cannot repopulate it.
6. 开源参考仅借鉴分层比较契约和指标组织，没有复制 `CodingxFaisal/bess-dispatch-optimizer` 代码，也未引入其依赖。项目正式许可证仍未确定。/ The reference informed structure only; no code or dependency was copied. Project licensing remains undecided.
