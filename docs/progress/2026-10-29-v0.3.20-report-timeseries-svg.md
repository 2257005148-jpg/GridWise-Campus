## 3. 关键实现与设计决策 / Key implementation and design decisions

1. 单次报告继续调用 `load_verified_comparison()`，直接消费 `DashboardResult.chart`；A/B 报告继续调用 `compare_verified_runs()`，并使用同一次公平性检查返回的 A、B 图表，不进行第二次未绑定读取。
2. SVG 只做坐标映射、图例、单位和时段轴渲染，不重新计算电费、购电量、峰值或优化结果。
3. 时序必须非空、与当前输入时段数一致；A/B 时间戳必须相同；每个点必须是有限数值。任一失败均在生成完整 HTML 和文件发布前抛出 `ReportError`。
4. 动态文本和 SVG 属性使用标准库 HTML 转义；SVG 提供 `<title>`、`<desc>`、图例、单位、时段刻度和真实序列最小/最大值说明。
5. 所有 CSS、SVG 和数据均内联；没有 JavaScript、远程字体、CDN、网络请求或新增依赖。
6. 图表采用现有报告的深蓝、青绿、金色和灰蓝，纵向排列，保持汇总指标与过程曲线的层次，不重做报告其他部分。
7. `publish_html_report()`、`ReportCancellation`、临时文件、`fsync` 和 `os.replace` 代码未修改。

## 5. 测试结果与关键数值 / Tests and key values

### 实际动态验证 / Dynamically verified

- 单次和 A/B 报告均生成三张内联 SVG；每个 SVG 可由标准库 XML parser 解析。
- 曲线点来自真实的 `chart["series"]`，报告可访问说明中的点数、最小值和最大值与该数据一致。
- 合成纯电费运行：电费约 `131.01 CNY`、购电量约 `247.02 kWh`、峰值 `90.00 kW`；无储能基线为 `162.50 CNY`、`240.00 kWh`、`60.00 kW`。
- 55 kW 峰值模式与纯电费模式 A/B：电费差 `+25.89 CNY`、购电量差约 `-3.12 kWh`、峰值差 `-35.00 kW`。
- 空时序、NaN 和 Infinity 在发布前失败，目标文件不存在。
- 原有损坏运行、不公平比较、缺失/非有限指标、拒绝覆盖、目录/链接、写入失败、替换及清理双故障、取消先完成和发布先完成路径继续通过定向回归。

### 静态审查 / Static review

- 未修改优化模型、求解器、独立审计器、运行产物格式或指标公式。
- A/B 曲线来自已通过场景、求解器、模型源码摘要、设备参数及基线一致性检查的同一 `HistoricalRunComparison`。
- 单文件发布与取消锁边界没有变化。

### 未执行 / NOT_RUN

- 完整 pytest：按阶段要求 `NOT_RUN`。
- Windows 浏览器人工视觉检查、打印和缩放验收：`NOT_RUN`。
- Linux、macOS、托管 CI：`NOT_RUN`。
- PDF/Word 导出、运行时间排序或批量报告：不在范围，`NOT_IMPLEMENTED`。
- 真实校园数据、设备或网络服务：`NOT_RUN`。
