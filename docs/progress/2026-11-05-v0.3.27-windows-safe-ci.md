## 1. Objective / 阶段目标

Replace the manual synthetic workflow that ran the complete test suite, real
solver, export generation, and independent auditor with a marker-gated Windows
CI entry point. The default workflow must run only unit, integration, and GUI
items that exclude `solver`, `audit`, and `slow`.

将原先会执行完整测试、真实求解、导出生成和独立审计的手动工作流，替换为由
pytest Marker 门禁保护的 Windows CI。默认流水线只允许执行排除 `solver`、
`audit` 和 `slow` 的 unit、integration 与 GUI 测试。

## 5. Safe commands and boundaries / 安全命令与边界

Collection gate / 收集门禁：

```powershell
python -m pytest --collect-only -q
```

Safe layers / 安全分层：

```powershell
python -m pytest -ra --tb=long -m "unit and not solver and not audit and not slow"
python -m pytest -ra --tb=long -m "integration and not solver and not audit and not slow"
python -m pytest -ra --tb=long -m "gui and not solver and not audit and not slow"
```

The existing Phase 2B collection hook still rejects missing or multiple primary
markers. Its autouse guard still blocks unmarked `SolverFactory` access and
independent auditor subprocesses. No classification rule was weakened.

Phase 2B 的收集钩子仍拒绝缺少主分类或具有多个主分类的测试；自动保护仍会阻止
未标记的 `SolverFactory` 调用和独立审计子进程。未降低任何分类或隔离标准。
