## 3. 关键实现与设计决策 / Design decisions

1. `OptimizationPolicy(mode, peak_cap_kw)` 只接受 `cost` 或 `peak_cap`。纯电费模式要求上限为 `null`；峰值模式要求有限、非负上限。
2. `ScenarioPreset` 保存稳定 ASCII ID、可显示 Unicode 名称、冻结设备参数与策略。峰值上限不得超过同一预设的 `grid_max_kw`。
3. 文件格式为 `format_version=1` 和 `presets` 数组；对象字段集合必须精确匹配。名称用 `casefold()` 判重。
4. 单文件上限为 128 KiB，预设数量上限为 100，名称上限为 80 字符，ID 上限为 64 字符。
5. 文件不存在时返回空元组；损坏、未知版本、非 UTF-8、重复键、`NaN`、`Infinity`、目录、链接或 junction 均失败关闭。
6. 保存前验证完整集合和现有文件；使用 `tempfile.mkstemp()` 独占创建同目录临时文件，写入后 `flush + fsync`，最后 `os.replace` 发布。
7. CRUD 返回新的元组，不修改调用方集合。自动创建 ID 使用标准库 `uuid4().hex`。
