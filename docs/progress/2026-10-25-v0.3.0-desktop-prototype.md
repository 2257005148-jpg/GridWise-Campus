## 3. 关键实现与设计决策 / Design decisions

官方 GitHub 包元数据评估：[Streamlit](https://github.com/streamlit/streamlit/blob/develop/lib/pyproject.toml) 为 Apache-2.0，运行依赖图较大；[Plotly Python](https://github.com/plotly/plotly.py/blob/main/pyproject.toml) 为 MIT，图表能力丰富但需新增依赖。本阶段选用现有 Python 的 Tkinter/Tk，无新增包或本地 Web 服务；两候选未安装。更详见[设计](../v0.3-desktop-design.md)。 / Tkinter was chosen for a local single-user prototype after reviewing the official alternatives.

界面先用 `import_energy_csv` 生成质量报告，`ready=false` 时运行按钮禁用；有效时序不超过 96 个时段才允许交互式求解。运行协调层仅组合已验证时序与合成设备参数，调用既有 `cli.run`，独立进程调用 `audit_exports.py`，通过后调用 `prepare_visualization_data`。费用、购电量、峰值和五张图均读取图表准备结果；UI 不重算指标。临时运行目录自动清理，原始 CSV 只读。 / Quality, solver, independent audit and chart preparation are separate gates.

## 6. 数值结果与依据 / Numeric results and basis

当前合成样例中，纯电费优化与无储能基线使用同一输入、小时步长及 `peak_grid_kw=max(grid_kw)`。既有模型的变量为购电、充/放电、光伏利用、SOC 和充电模式；目标为最小化 `Σ grid_kw × price_cny_per_kwh × step_hours`，保持功率平衡、SOC 递推、上下界、互斥和终端 SOC 约束。独立审计从原始合成 JSON、优化 CSV、基线 CSV 与汇总 JSON 复核：优化电费 131.01 元、购电量 247.02 kWh、峰值 90 kW；基线分别为 162.50 元、240.00 kWh、60 kW，绝对容差 `1e-5`，校验前不舍入。电费下降不代表峰值或购电量下降。 / Independent audit confirms the cost-only sample; energy and peak move in the opposite direction.
