# GridWise Campus v0.3.21 — 报告可读性小幅优化 / Report readability refinements

日期 / Date: 2026-10-29

## 1. 发现的问题 / Confirmed issues

静态检查发现两个可复现的显示缺陷：

1. SVG 纵轴固定使用 `:,.2f`。当合法序列达到 `1e12` 时，`1,000,000,000,000.00` 超出固定 `68px` 左边距；当非零刻度小于 `0.01` 时，多个刻度均显示为 `0.00`，掩盖实际差异。
2. `900` 宽 viewBox 在窄窗口直接缩小，图例和轴标签也随之缩小；原 CSS 没有最小可读宽度或图内横向滚动。

以上问题由确定性的 HTML 输出规则复现，不依赖浏览器主观判断。真实浏览器视觉验收仍单独标记为未执行。

## 2. 修改文件 / Modified files

- `src/gridwise/reports.py`：增加紧凑轴刻度格式；为 SVG 增加只影响图表区域的横向滚动容器和 `680px` 最小宽度。
- `tests/test_reports.py`：增加公开 HTML builder 的极大/极小刻度及窄窗口布局回归。
- `docs/report-export.md`：说明刻度、长序列与窄窗口规则。
- `docs/test-plan.md`：记录 v0.3.21 定向验收范围。
- `docs/progress/2026-10-29-v0.3.21-report-readability.md`：本报告。

本阶段没有修改曲线数据、指标、A/B 公平比较、报告发布、取消门闩、优化模型、CLI、运行产物或审计器。

## 3. 设计决策 / Design decisions

- `0` 继续显示为 `0`；绝对值大于等于 `100,000` 或小于 `0.01` 的非零刻度使用两位有效小数的科学计数法，其余刻度保留两位小数。
- 图表本体保持 `900×300` viewBox 和现有配色；只增加 `.chart-viewport` 横向滚动及 `680px` 最小宽度。
- 图题留在滚动区域外，避免窄窗口中标题随曲线一起滚走。
- 长序列仍只标注起点、中点和终点时段，不增加会重叠的逐点标签。
