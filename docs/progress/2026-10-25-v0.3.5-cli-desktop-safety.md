# GridWise Campus v0.3.5 阶段报告 / CLI and desktop safety review

## 1. 阶段目标与完成情况 / Goal and outcome

**动态验证 / Dynamically verified:** 合成临时文件证实旧 CLI 会覆盖 `summary.json` 的用户字节；新 CLI 默认拒绝四种同名导出，显式 `--overwrite` 才替换。发布前暂存完整结果；普通中途失败回滚，回滚本身失败时保留恢复副本。质量日志现在显示全部问题且错误检查再次禁用运行。Windows 可见 GUI 完成有效和无效输入路径。纯电费目标、数据契约、两个审计器未修改。 / The overwrite and truncated-issue defects were reproduced, corrected and tested. The optimization and audit contracts were not changed.

**未解决 / Open:** v0.3.4 的 `tk_focusNext` 间歇性异常根因仍未确定。本阶段重复运行又观察到 Tk 初始化时短暂读不到其自身 `ttk/scrollbar.tcl` 或 `icons.tcl`；这些文件随后存在。把独立 Tk 探针放入子进程后，焦点测试未再与同一 pytest 进程的其他 Tk 解释器互相干扰，但不能据此宣称 Tk 运行时问题已解决。 / Intermittent Tk runtime failures remain open.

## 3. 缺陷与复现 / Defects and reproduction

1. **CLI 覆盖 / Overwrite:** 修复前在临时输出目录写 `summary.json=b'USER-MARKER'`，调用 `run` 后标记消失，退出 0。修复后四种同名导出各自使 CLI 退出 2、旧字节不变；`--overwrite` 明确成功。注入后出现的 `baseline.csv` 冲突，先前新建文件被撤回且并发文件保留。注入第二文件替换失败，旧四文件字节恢复；再注入回滚失败，错误指向保留的恢复副本。 / Synthetic failure injection verifies normal rollback and incomplete-rollback recovery evidence.
2. **质量错误截断 / Truncated quality issues:** 修复前 15 条错误仅展示前 8 条，新增测试退出 1；修复后第 15 条可在有焦点的只读日志中读到，运行按钮禁用。 / Red then green regression.
3. **Tk 焦点 / Tk focus:** 最初 10 次混合重复有 5 次失败；一次完整堆栈指向 Tk 初始化时 `ttk/scrollbar.tcl` 暂不可读。另一次全量失败指向 `icons.tcl`，重新查询两文件均存在。改成独立子进程探针后 5 次混合重复为 0 失败。这隔离了测试解释器生命周期，**未确定** v0.3.4 `tk_focusNext` 错误的唯一根因。 / Evidence supports an environment/lifecycle interaction, not a proven root cause.

## 6. 可访问性、静态审查与证据缺口 / Accessibility and evidence limits

**Windows UI Automation 实查 / Observed UIA:** 本机 Tk 窗口控件树约 36 节点；许多输入、按钮、日志、指标和页签被暴露为无名称 `Pane`。界面可见文字和 Tk 自动化键盘事件通过，不等于屏幕阅读器能识别名称/角色。质量列表可以通过 Tab 到达并滚动到末项；错误状态有文字，不只靠颜色。 / Native Tk UIA semantics remain limited.

**静态审查 / Static review:** `core.py`、`data.py`、`audit_exports.py`、`audit_history.py` 无差异；无正式 `LICENSE`。符号链接目标在当前 Windows 权限下无法创建，相关自动化用例跳过；代码仍作拒绝检查。 / Static checks do not substitute for unrun link and assistive-technology behavior.

**NOT_RUN:** 屏幕阅读器、真人物理键盘、真实不同 DPI 显示器及跨屏移动、Linux/macOS GUI、托管 CI、数小时耐久性、恶意并发写入/进程崩溃注入、真实校园数据或设备。项目许可授权仍待有权人决定，未发布。 / These claims remain unverified.
