## 3. 实现与边界 / Implementation and boundaries

`import_energy_csv → build_scenario → publish_run [CLI 求解 → 独立 audit_exports.py → manifest/COMPLETE] → read_verified_run → prepare_visualization_data → Tk`。`summary.json` 由安全读取接口返回的已校验字节解析，GUI 不自行重算费用、电量或峰值。运行根目录默认为系统临时目录下 `gridwise-campus-runs`，用户可选择已有本地目录；最多列出 50 个匹配运行目录、扫描上限 1000 项。列表区分 `VALID`、`INCOMPLETE`、`DAMAGED`，选择时重新校验。结果目录不自动删除；临时场景 JSON 由上下文管理器清理。/ Charts use verified bytes only. History enumeration is bounded; selection rechecks files. Failed run directories remain for inspection.

Tk 后台任务继续以取消事件、代次号和主线程队列隔离。输入路径、时间步或运行根目录变化时，清空旧图表及选择；重复点击不会启动第二个任务。历史读取取消在安全读取前后及图表准备后检查，关闭窗口等待后台任务完成。/ Cancellation, generation IDs and the main-thread queue prevent stale display; close waits for workers.

`COMPLETE` 与哈希仅检查完整性，不能证明输入真实性、求解最优性、恶意本机写入者下的真实性或断电持久性。历史读取不重新执行独立审计；它依赖发布时审计和读取时完整性检查。/ Marker and hashes prove neither authenticity nor optimality. Historical reads do not rerun the auditor.

## 5. 合成指标 / Synthetic metrics

同一 `examples/synthetic-day.json`、相同时步和电价，经独立审计：优化方案费用 `131.01108033241 CNY`、购电量 `247.02216066482 kWh`、购电峰值 `90 kW`；无储能基线费用 `162.50 CNY`、购电量 `240 kWh`、购电峰值 `60 kW`。计算定义分别是 `Σ(grid_kw × price_cny_per_kwh × step_hours)`、`Σ(grid_kw × step_hours)`、`max(grid_kw)`。费用减少约 `31.49 CNY`，购电量增加约 `7.02 kWh`，峰值增加 `30 kW`；不得称为削峰或节能。/ Cost fell while purchased energy and peak increased. The three metrics remain distinct.

## 6. 未执行与风险 / NOT_RUN and risks

- `NOT_RUN`：Linux/macOS、托管 CI、真实校园数据或设备、真实多人并发操作、断电恢复、物理键盘与屏幕阅读器验收。/ These environments and real-world operations were not run.
- Tk `tk_focusNext` 和 Tcl 文件间歇异常根因仍为 `UNKNOWN`；本阶段测试未复现不表示已经修复。/ The earlier intermittent Tk/Tcl cause remains unknown.
- 默认运行根位于系统临时目录，操作系统清理可移除历史；需要长期保留时应由用户选择受控目录。目录可能在取消后保留未完成内容，但安全读取会拒绝。/ The default OS temp location is not durable; incomplete runs may remain but are rejected.
- 本地可写文件被恶意同步改写、路径竞态与断电持久性不属于完整保证；`read_verified_run` 的现有边界见[契约](../run-artifact-contract.md)。/ Local adversarial writes and power-loss durability remain outside the guarantee.
- 项目正式许可证尚未获授权决定；没有添加 `LICENSE`，也未发布。/ Project licensing remains undecided; nothing was published.
