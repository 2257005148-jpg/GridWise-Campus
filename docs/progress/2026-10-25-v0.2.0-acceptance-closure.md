## 3. 实现与设计决定 / Design decisions

沿用既有标准库实现，无 pandas、UI 框架、数据库或网络接口。输入 CSV 要求 `timestamp,load_kw,pv_kw,price_cny_per_kwh` 的精确顺序，UTF-8 可带 BOM，显式 `step_hours` 为 `(0,24]`，时间戳带 UTC 偏移并以绝对瞬间检查。文件 ≤32 MiB、物理行 ≤64 KiB、时段 ≤50,000、数值 token ≤128 字符，功率/电价为非负有限数且 ≤10¹²。失败时报告 `ready=false` 与可定位的 issue，时序为空。 / The existing strict, bounded, read-only contract remains in force.

图表层使用同一有效输入 CSV 对齐两方案时间戳和负荷、可用光伏、电价回显；费用 `grid_kw × price_cny_per_kwh × step_hours`、购电量 `Σ(grid_kw × step_hours)`、峰值 `max(grid_kw)`。指标分别报告，不把电费下降称为削峰或节能。 / Cost, grid energy and peak are separate metrics.

## 6. 数学模型与独立数值 / Model and independent numbers

**静态模型描述 / Static model description:** 输入为负荷 `L[t]`、可用光伏 `A[t]`、电价 `p[t]`、步长 `Δt`、购电/储能上界及效率。变量 `G[t]` 购电、`C[t]` 充电、`D[t]` 放电、`P[t]` 光伏利用、`E[t]` 期末能量、二元充电模式 `z[t]`。目标 `min Σ G[t] p[t] Δt`。约束为 `G+D+P=L+C`、`E[t]=E[t-1]+Δt(ηc C-D/ηd)`（首步用 `E0`）、购电/SOC/功率/光伏界、充放电互斥和末端 `E[last]=Eend`。本阶段未更改模型。 / Cost-only MIP remained unchanged.

**动态独立审计 / Dynamic independent audit:** 用原始合成 JSON 与两份 CSV、汇总 JSON 独立校验，绝对容差 `1e-5`。优化电费 131.01 元、购电量 247.02 kWh、峰值 90 kW；无储能基线电费 162.50 元、购电量 240.00 kWh、峰值 60 kW。逐时成本、累计成本、购电量与峰值还由两时段手算测试精确断言。优化方案电费低 31.49 元，但多购电约 7.02 kWh，峰值高 30 kW。 / The synthetic sample supports a cost reduction, not peak or energy reduction.
