## 6. 数值结果及依据 / Numeric results and basis

原始合成 JSON 与新 CSV 的六行负荷、光伏、电价和时间戳在测试中逐行一致。两方案均为 1 小时步长，峰值定义 `max(grid_kw)`。优化方案电费 **131.01108033240996 元**、购电 **247.02216066481995 kWh**、峰值 **90 kW**；无储能基线电费 **162.50 元**、购电 **240 kWh**、峰值 **60 kW**。图表指标的“优化减基线”分别为 **−31.48891966759004 元**、**+7.02216066481995 kWh**、**+30 kW**。 / Cost decreases while grid energy and peak increase.

费用用 `Σ grid_kw × price_cny_per_kwh × step_hours`，购电量用 `Σ grid_kw × step_hours`，峰值用 `max(grid_kw)` 逐行计算；图表准备核对导出汇总，独立审计器另从原始 JSON 和两个 CSV 检查功率、SOC 及汇总，绝对容差 `0.00001`、检查前不舍入。降低电费不称为削峰或降低能耗。 / Metrics have separate definitions and an independent export audit.

## 7. 核心模型与独立校验 / Model and independent check

**静态审查，未修改 / Static review, unchanged:** 变量 `grid[t]`, `charge[t]`, `discharge[t]`, `pv_used[t]`, `soc[t]`, 二元 `mode[t]`；目标 `min Σ grid[t] × price[t] × step_hours`。功率平衡 `grid + discharge + pv_used = load + charge`；SOC 递推 `soc[t] = prior + step_hours × (ηc × charge − discharge/ηd)`；另有限制初始/终端 SOC、容量、功率、光伏与充放电互斥，且求解器需正常最优终止。无储能基线禁用充放电。 / Cost-only dispatch remains unchanged.

**动态验证 / Dynamic validation:** 提交后合成样例求解和独立导出审计通过；新图表数据核对两方案同一输入回显及指标。既不证明输入真实，也不代表 UI 或真实系统已验收。 / Only synthetic offline behavior was exercised.
