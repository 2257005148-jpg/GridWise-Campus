## 3. 关键实现、安全决策与 Bug / Implementation, safety decisions and bug

- 初始 HEAD 为 `d26c40c8606cbce6ba09b5f0016b5045bfed5ff0`，是指定基线 `e88022786cf27267b68e886771c37f894f07f8dc` 的 v0.1.8 报告后继提交。初始仅五份更早报告未跟踪，无远程且仅有主工作树；没有重置。 / The requested base was an ancestor of the actual report-only HEAD.
- **可复现缺陷 / Reproduced bug:** 当前模型源码不可读时，`model_version()` 抛出 `AuditError`，历史入口未处理，导致没有结构化 JSON 状态。使用受控合成临时仓库、令当前模型读取抛出该错误，修复前单例测试退出 1；修复后 `current_context=UNKNOWN` 且含定位信息，历史独立预检与算术仍能 `PASS`，单例退出 0。该异常仅影响当前上下文，不放宽历史安全预检。 / An unavailable current source now produces an explicit independent unknown verdict.
- **复用安全边界 / Reused safety boundary:** 历史提交、`run-v015` schema、Git blob、模型/锁/审计器摘要、Python/依赖版本在历史脚本运行前核对；检出后再次检查 HEAD、审计器和锁字节。命令局部禁用钩子、fsmonitor 和外部 attributes，避免换行转换；历史脚本只读取经核对的四文件快照。历史模型不执行；未通过历史预检时 `arithmetic_physics=NOT_RUN`。既有合成回归覆盖创建/清理失败、残留路径、原件变化、错误锁与属性及状态分离。 / Historical execution remains limited to the pinned standard-library auditor.
- `--repo` 仅用于本项目或受控临时仓库。哈希、版本与提交号只关联给定字节，不能证明输入、wheel 或仓库来源可信；前后散列不能发现短暂替换后恢复。 / This is not a general sandbox or authenticity proof.

## 7. 数学模型与独立校验 / Mathematical model and independent check

**静态审查，未修改 / Static review, unchanged:** `grid[t]`, `charge[t]`, `discharge[t]`, `pv_used[t]`, `soc[t]` 与二元 `mode[t]`；目标为 `min Σ grid[t] × price[t] × step_hours`。功率平衡 `grid + discharge + pv_used = load + charge`；SOC 递推 `soc[t] = prior + step_hours × (ηc × charge − discharge/ηd)`；另有初始/终端 SOC、容量、充放电功率、光伏与互斥约束。求解器必须正常且最优终止。无储能基线关闭充放电。 / The cost-only MIP and baseline policy were preserved.

**动态校验 / Dynamic check:** 当前提交的合成结果通过独立导出审计；旧结果在对应历史上下文下通过历史算术审计，但没有重新运行历史求解器。 / Historical exports were audited, not re-solved.
